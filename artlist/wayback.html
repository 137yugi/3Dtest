このログが採用している証拠基準

Wayback Availability API で空の応答が返った場合、それはその照会で closest snapshot が返らなかったことだけを記録します。アーカイブ不存在、削除、改変を推定しません。逆に索引が返っても、本文を取得できなければ当時の文言を引用しません。

他の被害申告者が今すぐやること

同じ形式で証拠を集めれば、各人の記録を比較できます。推測は書かず、表示された画面と操作時刻を残してください。

画面録画を先に開始

PCの日時、ブラウザURL、ログイン中のプラン名、残高、利用履歴、次回支払額、自動更新状態を一続きで映します。途中でページを再読み込みしてください。

生成前と生成後を別々に保存

モデル名、モード（T2V / I2V / R2V）、秒数、解像度、参照画像・動画・音声数、Generateボタン付近のクレジット表示、実際の利用履歴を保存します。

購入時の表示を探す

広告、メール、SNS投稿、チェックアウト、領収書、ブラウザ履歴、スクリーンショット、動画、他人へ送ったメッセージを探します。後から作った再現画像は原本と混ぜないでください。

現在のページを保存

PDF、HTML、スクリーンショット、画面録画を同時に作成します。ファイル名へUTCまたはJSTの取得時刻を入れ、原本は編集しません。

ハッシュを計算

SHA-256を記録すると、後からファイルが変わっていないことを説明しやすくなります。メインハブのローカルハッシュツールも利用できます。

個人情報を複製してから黒塗り

原本は非公開保管し、SNS公開用の複製だけを黒塗りします。カード番号、住所、メール、アカウントID、クライアント名、案件金額、APIキーを公開しないでください。

現在のページをWaybackへ保存

過去の証拠にはなりませんが、現在の表示を将来比較するために保存できます。保存日時と対象URLを記録してください。
